Features

  1. [CORE ARCHITECTURE]
  2.     * Database-driven GUI
  3.     * Interchangeable database & config file between machines and operating systems
  4.     * Lazy loading: instantly opening of huge game lists
  5.     * Native Windows/macOS GUI code displaying 1000s of games fluently, even on old CPUs
  6.     * Ultra performance: 100 ms boot time (any CPU), 15 s MAME import data (modern PC/Mac)
  7. [MAIN WINDOW]
  8.     * Layout: toolbar, folder tree, sortable machine list, software list and a details pane
  9.     * List options
  10.     * Customizable columns
  11.     * Icons for machine properties
  12.     * Favorites, play counts and last played time
  13.     * Fonts choice
  14. [FOLDER TREE BUILT-IN FOLDERS]
  15.     * General: All Machines, Advanced Search results, Collections.
  16.     * Personal: Favorites, Recently Played, Played at least once, Custom Game Options.
  17.     * ROM state: Available/Unavailable, a ROM Audit group (Complete, Present, Incomplete, Bad, Missing, Not scanned), Dumping Status, Requires CHD.
  18.     * Structure and status: Parents, Clones, Prototype, Mechanical/Non-mechanical, Driver Status, Save State.
  19.     * Hardware: CPU, Audio chip, Stereo, Samples, Free Play, BIOS (with recursive parent/clone membership), Screen Type, Screens, Orientation, Resolution, Refresh Rate, Controls, Joysticks (by way count/type), Players
  20.     * Metadata: Manufacturer, Year, Source File, Arcade Systems, Arcade cabinets by decade (70s, 80s, 90s, 2000s) and by game genre per decade
  21.     * Software: Use Software List and Software Lists.
  22.     * INI Files.
  23.     * Folder actions: Audit, Pie Chart and Collection operations
  24. [ADVANCED SEARCH]
  25.     * Machines and software
  26.     * Three syntaxes can be mixed freely: Plain words and quoted phrases, Natural-language keywords andSQL-like field expressions
  27.     * Text search inside info files: history:, mameinfo: and mameversion:
  28.     * Boolean flags
  29. [ROM AUDITING]
  30.     * Quick Scan checks file names only. Scan ROMs verifies CRCs and sizes.
  31.     * ZIP and loose-folder support
  32.     * Full lookup chain: clone → parent → BIOS, plus device ROMs and default-BIOS handling.
  33.     * CHD checking
  34.     * Results are Complete, Present (not CRC-verified), Incomplete, Bad and Missing.
  35.     * Scan cache
  36.     * Scan targets: machines, software lists or both, with a per-software-list selection.
  37.     * Audit scopes: the selected machine, the selected software, a whole folder, or the whole software pane.
  38. [DETAILS PANE TABS]
  39.     * Info: a full machine summary
  40.     * Files: ROMs, CHDs and Samples with audit state per file
  41.     * History: history.xml and .dat content (history, mameinfo and similar)
  42.     * Images: artwork viewer
  43.     * Custom: a configurable tab with an image half and a text half, each choosable
  44. [SOFTWARE BROWSER]
  45.     * Details pane: Info, Files, History, Images (Snapshots, Titles, Covers, Manuals) and Custom.
  46.     * Running software: it works out which machines can run the list: “Run on which machine?”
  47.     * Collections and ROM Audit for software items
  48. [LAUNCHING GAMES]
  49.     * Game Options can be set globally (Default Game Options) or per machine (Game Options)
  50.     * A global extra-args setting and a “Custom Game Options” folder.
  51. [METADATA IMPORT]
  52.     * Reads .ini category files from a configured folder and .dat and history.xml files from another.
  53.     * These power the genre folders, Game Genre and Machine Type columns, History tab, and history:/mameinfo: searches.
  54. [SETTINGS AND UI CUSTOMIZATION]
  55.     * Settings dialog
  56.     * Interface Options
  57.     * Themes
  58.     * Context menus: right-click on machines, folders and software items.
  59. Folder list with advanced built-in folder filters and INI file support:
  60. Machine Type.ini
  61.     Multiplayer.ini
  62.     series.ini
  63.     catlist.ini
  64. Gaming History's history.xml support
  65. DAT file support:
  66.     command.dat
  67.     gameinit.dat
  68.     mameinfo.dat
  69.     messinfo.dat
  70. Snapshots support for machines and software lists: snapshots
  71. Cabinet images support: cabinets
